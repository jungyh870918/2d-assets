# 라이선스 기록

에셋을 `01_SOURCE/` 에 넣을 때마다 이 폴더에 `<vendor>_<pack>.md` 를 만든다.
확인 전에는 생성 파이프라인에 넣지 않는다.

## 템플릿

```markdown
# <팩 이름>

- 출처 URL:
- 제작자:
- 구매일 / 버전:
- 가격:
- 라이선스 원문 위치: (다운로드 zip 내 파일명 또는 판매 페이지 섹션)

## 허용
- [ ] 게임 내 상업적 사용
- [ ] 수정(색변경 / 파츠 조합 / 리사이즈)
- [ ] 클라이언트 작업물에 사용

## 금지
- [ ] 에셋 자체 재배포 / 재판매 (거의 항상 금지)
- [ ] 생성형 AI 학습 데이터 사용 (거의 항상 금지)
- [ ] 크레딧 표기 필요 여부:

## 메모
```

## 공통 주의

- **재판매 금지**: 구매 에셋을 조합해 만든 결과물을 다시 "에셋팩"으로 파는 것은
  거의 모든 라이선스에서 금지. 게임 안에서 쓰는 것과는 다른 문제.
- **AI 학습 금지**: Unity Asset Store 약관 및 다수 itch.io 에셋이 AI/ML training
  용도 사용을 명시적으로 금지. 조합/색변환/코드 수정은 별개로 허용되는 경우가 많음.
- 각 상품의 실제 라이선스 문구를 항상 직접 확인할 것. 위 요약은 일반론일 뿐이다.
